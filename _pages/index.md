Welcome to the official website for Lakeland University Japan's CPS 200 — Programming I course for Spring 2026. This course is taught by [Kyu Hur](https://scholar.google.com/citations?user=p-TpuTsAAAAJ). To contact, email [khur@japan.lakeland.edu](mailto:khur@japan.lakeland.edu). Past presentations, textbooks, videos, and supplementary materials are available through this website. Refer to the [Course Syllabus](files/CPS 200 - Syllabus.pdf) for details of this course.

This course is an introduction to computer programming. There is an emphasis on problem solving techniques, structured programming, top-down program design, control structures, and functions. MAT 140 — Advanced Algebra is a prerequisite for this course. The following are the learning outcomes for this course.

• Develop the concepts of computer systems and computer programming.
• Demonstrate a basic understanding of binary numbers and their role in computer programming.
• Write clear accurate programs in a high-level language.
• Draw flowcharts of programs.
• Write program codes to get input data and send output data.
• Develop the concept of functions and construct functions.
• Write programs that use selection, loops and functions.
• Solve simple problems using fundamental programming techniques and basic problem-solving
skills.
• Develop programs to implement real-life applications.
